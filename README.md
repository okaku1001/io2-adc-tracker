# 管线动态

公开的静态站点，整理生物医药成药、管线与竞品的已核更新。以康方生物已公布的全部成药、管线和平台技术为底盘，记录已核临床与监管变动，并延伸到与之构成竞争或合作的具体品种。不把再鼎、亚盛、金斯瑞、百济、信达、恒瑞、君实、荣昌等公司的整条管线无差别并入。覆盖仍在按已核材料补全，不表示已经穷尽。

站点地址：<https://okaku1001.github.io/io2-adc-tracker/>（仓库名 io2-adc-tracker 仍沿用，不改。）

同一条试验、同一个药、同一件监管事项只保留一个条目。新进展并进原条目的时间线。每日动态页只作索引。阅读时可先看首页的最近动态和局面图，再进入「管线与竞争」按品种展开已挂上的试验、竞争与合作。

公开站每天约 8:30（北京时间）更新一次，周末也更新。已上线错误仍尽快在原条目改正。

本站为公开信息整理，不构成投资建议。
