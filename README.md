# IO2.0+ADC 临床追踪

公开的静态站点，记录康方生物已公布管线的核心临床与监管变动，以及可能与这些管线竞争或合作的品种。既有条目仍以依沃西（AK112 / ivonescimab / SMT112，商品名依达方）与卡度尼利（AK104，商品名开坦尼）为主线，覆盖已扩大到康方已上市、已进临床及公司已点名的在研品种，并不把再鼎、信达、百济等公司的整条管线无差别并入。

站点地址：<https://okaku1001.github.io/io2-adc-tracker/>

同一条试验、同一个药、同一件监管事项只保留一个条目。新进展并进原条目的时间线。每日动态页只作索引。

公开站每天约 8:30（北京时间）更新一次，周末也更新。已上线错误仍尽快在原条目改正。2026-11-16 起曾改为严格每周一更新；11-26 先补上 11-23 未更的一轮，随后恢复日更并扩大覆盖。

本站为公开信息整理，不构成投资建议。

```bash
python3 content/make_data.py   # 若改了 content/*.py
python3 build.py               # 读取 data/entries.json 与 data/daily/*.json，写出 HTML
```
