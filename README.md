# IO2.0+ADC 临床追踪

公开的静态站点，以康方生物已公布的全部成药、管线和平台技术为底盘，记录已核临床与监管变动，并延伸到与之构成竞争或合作的具体品种。既有条目仍以依沃西（AK112 / ivonescimab / SMT112，商品名依达方）与卡度尼利（AK104，商品名开坦尼）为主线，并已补入其他已点名成药、管线和平台；不把再鼎、亚盛、金斯瑞、百济、信达、恒瑞、君实、荣昌等公司的整条管线无差别并入。覆盖仍在按已核材料补全，不表示已经穷尽。

站点地址：<https://okaku1001.github.io/io2-adc-tracker/>

同一条试验、同一个药、同一件监管事项只保留一个条目。新进展并进原条目的时间线。每日动态页只作索引。

公开站每天约 8:30（北京时间）更新一次，周末也更新。已上线错误仍尽快在原条目改正。2026-11-16 起曾改为严格每周一更新；11-26 先补上 11-23 未更的一轮，随后恢复日更，并把覆盖基准调整为成药、管线、平台技术及与之竞争或合作的具体品种。

本站为公开信息整理，不构成投资建议。
